# Eve v1.0.0

2026-09-08에 고정한 StackChan Eve의 첫 안정 운영 기준선입니다. 이 태그는
기존 Home Assistant 애드온의 `2.8.0-beta.3` 버전을 대체하지 않으며, 이브의
Windows relay + WSL 독립 서버 구성만 식별합니다.

## 포함 기능

- OpenRouter LLM, OpenAI STT/TTS를 분리한 한국어 대화 파이프라인
- 사용자를 `교수님`으로 부르는 짧고 활기찬 이브 페르소나
- 대화 기억, 명시적 카메라 요청, 펌웨어 기본 후속 듣기 흐름
- 감정별 컬러 그라데이션과 심박 속도를 표현하는 연속 LED
- TTS 음량 및 피치 보정
- 무음·주변 소음은 음성 재질문 없이 조용히 대화 상태만 복구

## 안정성 기준

- 서버가 보내는 머리 서보 동작, 큰소리 서보 반응, 자율 서보 행동은 기본 비활성
- LED 제어는 머리 동작과 분리되며 장치 오류가 발생하면 해당 세션에서 자동 중단
- 빈 STT 결과도 `tts:start`/`tts:stop` 무음 핸드셰이크로 종료하여 펌웨어가 멈추지 않음
